## 步驟六：執行資料庫 Migrations

> **前提**：MySQL Docker container 必須在執行中。
> 若尚未啟動：`cd docker && docker-compose up -d`

依序執行以下三個 migration：

### Migration 012 — 新增 must_change_password 欄位

```bash
docker exec -i chungyo_mysql mysql --default-character-set=utf8mb4 -ucy7191 "-pK!ng.19960827" chungyoOffical < database/migrations/012_user_must_change_password.sql
```

**內容說明**：
```sql
ALTER TABLE users
  ADD COLUMN must_change_password TINYINT(1) NOT NULL DEFAULT 0
  AFTER is_active;
```

### Migration 013 — 修正角色描述中文

```bash
docker exec -i chungyo_mysql mysql --default-character-set=utf8mb4 -ucy7191 "-pK!ng.19960827" chungyoOffical < database/migrations/013_fix_role_descriptions.sql
```

**內容說明**：更新三個預設角色的中文說明（解決亂碼問題）。

### Migration 014 — 新增 delete 權限

```bash
docker exec -i chungyo_mysql mysql --default-character-set=utf8mb4 -ucy7191 "-pK!ng.19960827" chungyoOffical < database/migrations/014_add_delete_permission.sql
```

**內容說明**：為全部 16 個模組新增 `delete` action 的權限記錄，並自動授予 `super_admin`。

## 新功能說明

同步完成後，後台新增以下功能：

| 路徑 | 功能 | 可見角色 |
|------|------|---------|
| `/admin/login` | 登入頁 | 所有人 |
| `/admin/change-password` | 強制改密頁（首次登入） | 已登入 |
| `/admin/users` | 帳號管理（新增/停用/刪除帳號） | super_admin |
| `/admin/roles` | 角色管理（設定各角色的模組權限） | super_admin |

### 權限矩陣說明

角色管理頁面現在支援三種權限：
- **讀取**（read）：可查看資料
- **寫入**（write）：可新增/修改資料
- **刪除**（delete）：可刪除資料

## 若遇到問題

### 「Unknown column 'must_change_password'」錯誤

代表 Migration 012 未執行，重新執行步驟六的第一個 migration。

### 登入後閃回登入頁

1. 確認 `backend/.env` 的 `JWT_SECRET` 與家中電腦相同
2. 確認 Migration 012 已執行（`must_change_password` 欄位存在）
3. 清除瀏覽器的 localStorage：開發者工具 → Application → Local Storage → 全部清除
